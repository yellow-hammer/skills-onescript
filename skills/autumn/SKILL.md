# Autumn (ОСень)

Фреймворк компонентных приложений для OneScript с Dependency Injection и Inversion of Control. Разрешает зависимости конструкторов автоматически: не нужно вручную создавать цепочки объектов и передавать параметры во все точки создания.

Ниже — autumn 5.0.2. На последней четвёрке, 4.3.15, эти же рецепты компилируются. Отдельной инструкции для четвёрки нет: [versions/4.md](versions/4.md) только фиксирует, что поломки нет.

## Версия

Версию бери из `oscript_modules/autumn/opm-metadata.xml`, элемент `version`. Если каталога модулей нет — из `.ЗависитОт("autumn", "...")` в `packagedef`. Мажор 4: прочитай [versions/4.md](versions/4.md) и не выдумывай второе API. Мажор 5: достаточно этого файла и [versions/5.md](versions/5.md).

Описание аннотации, которой нет ниже, читай из поставки пакета: `oscript_modules/autumn/src/internal/Классы/Аннотация*.os`. В шапке класса написано, куда она ставится (конструктор, метод, поле, параметр) и приведён пример. Каталог `docs` в пакет не входит. Расширение файлов в поставке — `.os`.

## Аналогии Spring Boot

Таблица только для узнавания аннотации. В коде пиши осенние имена. `@Component` и остальные аннотации Spring в языке нет, правила внедрения у Autumn другие: параметр конструктора без `&Пластилин`, `&Деталька` или `&Блестяшка` не внедряется, поле в `ПриСозданииОбъекта` ещё пустое.

| Autumn | Spring Boot |
| --- | --- |
| `&Желудь` | `@Component` |
| `&Дуб` | `@Configuration` |
| `&Завязь` | `@Bean` |
| `&Пластилин` | `@Autowired` |
| `&ФинальныйШтрих` | `@PostConstruct` |
| `&Напильник` | `BeanPostProcessor` |
| `&Деталька` | `@Value` |
| `&Табакерка` | `ObjectProvider` |

## Душные имена

Пакет [autumn-killjoy-flavour](https://github.com/autumn-library/autumn-killjoy-flavour) 1.3.0 даёт вторые имена тем же аннотациям. Подключай его, только если в проекте уже есть `#Использовать autumn-killjoy-flavour`. Без этой строки пиши осенние имена: `&Желудь`, `&Пластилин`, `&Деталька`. Английские аннотации Spring (`@Component`, `@Autowired`) в языке нет.

Душное имя — псевдоним через `&ПсевдонимДля`. Правила внедрения не меняются: поле по-прежнему пустое в конструкторе, параметр без аннотации не внедряется.

| --- | --- |
| `&Желудь` | `&Компонент` |
| `&Характер("Компанейский")` | `&Прототип` |
| `&Верховный` | `&Приоритетный` |
| `&Дуб` | `&Конфигурация` |
| `&Завязь` | `&ФабричныйМетод` |
| `&Заготовка` | `&ИнициализаторПриложения` |
| `&Напильник` | `&ОбработчикКомпонента` |
| `&Приемка` | `&ОбработчикОпределенияКомпонента` |
| `&Спецификация` | `&ФазаПриложения` |
| `&ОсобоеОбращение` | `&ПравилаОбработки` |
| `&Прозвище` | `&Квалификатор` |

| `&Блестяшка` | `&ПроизвольныйПараметр` |

Зависимость пакета — autumn от 4.3.13.

## Точка входа

```bsl
#Использовать autumn
#Использовать "Каталог/С/Классами"

Поделка = Новый Поделка();
Поделка.ЗапуститьПриложение();
```

Классы с аннотациями Autumn должны быть подключены через `#Использовать` до `Новый Поделка()`. Конструктор поделки сканирует уже загруженные типы.

`Поделка.ЗапуститьПриложение()` вызывает желуди `&Рогатка`. В стартовом скрипте это замена `Поделка.НайтиЖелудь()` и ручному вызову метода.

```bsl
Процедура ПриЗапускеПриложения() Экспорт
	// поля &Пластилин и &Деталька здесь уже заполнены
КонецПроцедуры

&Рогатка
Процедура ПриСозданииОбъекта()
КонецПроцедуры
```

По умолчанию рогатка стартует в фоновом задании (`ЗапускатьВФоне = Истина`), и приложение ждёт завершения запущенных фоновых рогаток. Рогатка с `ЗапускатьВФоне = Ложь` выполняется в текущем потоке и не пускает остальные, пока `ПриЗапускеПриложения` не вернётся. Порядок запуска задаёт `&Порядок` от 1 до 999998: меньше число — раньше старт. Выключить все рогатки: деталька `core.ЗапускатьРогатки` со значением `false`.

## Получение компонента

```bsl
Поделка = Новый Поделка();
Обновлятор1С = Поделка.НайтиЖелудь("Обновлятор1С");
```

Идентификатор совпадает с именем класса или с параметром `&Желудь("Идентификатор")`. `НайтиЖелудь` нужен в тесте и когда экземпляр требуется самому скрипту.

## Ключевые аннотации

- **&Желудь("Идентификатор")** — класс регистрируется как компонент (желудь). Без параметра используется имя класса. Зависимость в конструкторе помечай явно: `&Пластилин`, `&Деталька` или `&Блестяшка`. Параметр без аннотации при `Новый Поделка()` даёт «Неизвестный тип прилепляемой частицы».

- **&Верховный** — при совпадении имён побеждает этот желудь. Два таких желудя с одним именем дают исключение. В CLI так перекрывают встроенный `ОписаниеКонсольногоПриложения`. Указывается вместе с `&Желудь`.

- **&Дуб** — класс-фабрика: сам тоже желудь, а методы с `&Завязь` возвращают другие желуди.

- **&Завязь** — метод внутри `&Дуб`, возвращающий экземпляр. Параметры метода помечаются `&Пластилин`, `&Деталька` или `&Блестяшка`.

Пример желудя:

```bsl
&Желудь("Обновлятор1С")
Процедура ПриСозданииОбъекта(&Пластилин ПроверяторВерсий, &Деталька Настройки)
КонецПроцедуры
```

Пример дуба с завязью:

```bsl
&Дуб
Процедура ПриСозданииОбъекта()
КонецПроцедуры

&Завязь
Функция МояЛегасиКоманда() Экспорт
	Возврат Новый МояЛегасиКоманда();
КонецФункции
```

## Деталька

`&Деталька` — настройка приложения, не желудь. Ставится на поле, параметр конструктора, сеттер `УстановитьИмя` или параметр `&Завязь`.

Ключ настройки — параметр `Значение`. Если он пуст, берётся имя поля или параметра. У сеттера отбрасывается префикс `Установить`. Вложенный объект записывается через точку: `Настройки.ПутьКФайлу`. `ЗначениеПоУмолчанию` подставляется, когда ключа нет ни в одном источнике.

```bsl
&Деталька
Перем Логин;

&Деталька(Значение = "ПрочиеНастройки.Настроение", ЗначениеПоУмолчанию = "Хорошее")
Перем Настроение;

&Желудь
Процедура ПриСозданииОбъекта(&Деталька Порт)
КонецПроцедуры
```

Файл называется `autumn-properties` с расширением `.json`, `.yaml`, `.yml` или `.ini`. Ищется в текущем каталоге, в профиле пользователя, в локальном каталоге данных приложений и в подкаталоге `src` каждого из них. Файл в текущем каталоге перекрывает такой же ключ в `src`. Если рядом лежат `.yaml` и `.json`, остаётся значение из yaml.

```json
{
	"Логин": "user",
	"Порт": 3333,
	"ПрочиеНастройки": {
		"Настроение": "Хорошее"
	}
}
```

Из кода то же значение читается так: `Поделка.НайтиДетальку("Логин", "guest")`.

Переменная среды с тем же ключом остаётся: файл её не затирает. Проверено прогоном `Поделка.НайтиДетальку` на autumn 5.0.2.

## Финальный штрих

Поле `&Пластилин` и `&Деталька` внутри `ПриСозданииОбъекта` ещё пустое: autumn заполняет его после конструктора. Значение, нужное при создании, объявляй параметром: `Процедура ПриСозданииОбъекта(&Пластилин Конфигурация)`.

Когда поля уже внедрены, повесь `&ФинальныйШтрих` на экспортный метод. Он вызывается после конструктора и после внедрения в поля и сеттеры. Методов может быть несколько, порядок их вызова не гарантирован.

```bsl
&Пластилин
Перем Конфигурация;

&ФинальныйШтрих
Процедура ПослеВнедрения() Экспорт
КонецПроцедуры

&Желудь
Процедура ПриСозданииОбъекта()
КонецПроцедуры
```

В `ПриЗапускеПриложения` у `&Рогатка` поля тоже уже заполнены: метод вызывается после инициализации желудя.

## Грабли

Сверено на autumn 5.0.2. На 4.3.15 те же конструкции компилируются.

- `&Желудь`, `&Дуб`, `&Рогатка` и `&Контроллер` стоят сразу перед `Процедура ПриСозданииОбъекта`, после объявлений `Перем`. Аннотация в начале файла с `Перем` между ней и конструктором компонент не регистрирует: позже будет «Не удалось получить определение Желудя».
- Не вызывай `Поделка.ПросканироватьКаталог`, `ДобавитьЖелудь`, `ДобавитьДуб`, `ДобавитьНапильник`, `ДобавитьЗаготовку`, `ДобавитьРогатку`, `ДобавитьАннотацию` и модули `Осень`, `ТипыПрилепляемыхЖелудей`. В 5.0.2 этих методов нет. В 4.3.15 вызов компилируется и ничего не регистрирует.
- В `autumn-properties.json` не задавай `rootLogger`. Уровень `WARN` на корневом логгере глушит статистику OneUnit.

## Рекомендации

- Один класс — одна ответственность. Зависимости передавай через конструктор.
- `Поделка.НайтиЖелудь` вызывай в точке входа только если скрипту нужен сам экземпляр, и в тесте. Запуск приложения — `&Рогатка` и `Поделка.ЗапуститьПриложение()`.
- Настройки приложения клади в `autumn-properties` и читай через `&Деталька`.
