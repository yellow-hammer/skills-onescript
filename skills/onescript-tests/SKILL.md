# Тесты OneScript

Новый пакет на OneUnit: в `packagedef` стоят `.РазработкаЗависитОт("oneunit")` и `.РазработкаЗависитОт("asserts")`. Если в манифесте уже `1testrunner`, оставайся на нём и не переписывай набор на OneUnit. В `oscript-library` так чаще, чем OneUnit. У части пакетов раннера в манифесте нет: не добавляй его сам.

`opm test` и `opm run test` оба запускают `tasks/test.os`. В пакете на OneUnit скрипт вызывает локальный раннер:

```
oscript_modules/bin/oneunit execute -d ./tests --junit out/junit.xml
```

На Windows это `oscript_modules\bin\oneunit.bat`. Если в `packagedef` указан `1testrunner`, `tasks/test.os` поднимает `Новый Тестер`, а не `oneunit execute`. Этот скрипт не заменяй. Длинный текущий каталог даёт `PathTooLongException`. Обход: `subst` на короткий диск, прогон, затем снять диск.

## Файл теста

```bsl
#Использовать asserts
#Использовать "../src"

&Тест
&ОтображаемоеИмя("Человекочитаемое описание проверки")
Процедура ИмяТеста() Экспорт
	Ожидаем.Что(Результат, "пояснение").Равно(Эталон);
КонецПроцедуры
```

Аннотации ниже относятся к OneUnit. `&Тест` и `Ожидаем.Что` пишут оба раннера: по ним раннер не выбрать, смотри `packagedef`.

OneUnit: `&ПараметризованныйТест`, `&ИсточникЗначение`, `&ПередКаждым`, `&ПослеКаждого`, `&ПередВсеми`, `&ПослеВсех`, `&ОтображаемоеИмя`, `&Выключен`, `&Тег`. Обнаружитель oneunit не вызывает `ПолучитьСписокТестов`.

Проверки: `Ожидаем.Что(X).Равно(Y)`, `.ЭтоИстина()`, `.ЭтоЛожь()`, `.ЭтоНеопределено()`, `.Содержит(...)`, `.Больше(...)`, `.Не_()`. Исключение: `Ожидаем.Что(Объект).Метод("Имя", МассивПараметров).ВыбрасываетИсключение()`.

`&ПередВсеми` не сохраняет состояние: OneUnit создаёт новый экземпляр набора на каждый тест, переменная модуля из `&ПередВсеми` в тесте будет `Неопределено`. Инициализируй в `&ПередКаждым` или функцией-константой.

## Фикстуры

Файл, документ, JSON, `.env` клади в `tests/fixtures/`, не строкой в коде. Путь от каталога теста. `ТекущийСценарий().Каталог` внутри теста указывает на `tests`, хотя раннер собирает точку входа во временном файле:

```bsl
Функция Фикстура(Знач ИмяФайла)
	Возврат ОбъединитьПути(ТекущийСценарий().Каталог, "fixtures", ИмяФайла);
КонецФункции
```

Тест, который меняет файл, работает на копии. Строкой в коде остаётся аргумент, который метод и так принимает строкой, и фабрика, где набор значений перебирается в самом тесте.

## 1testrunner

Регистрация: `ПолучитьСписокТестов` или методы с `&Тест`. Хук `&Перед` и процедура `ПередЗапускомТеста` необязательны. Параметры задаются `&Параметры`. В `testrunner.os` нет `&ПередКаждым`, `&ИсточникЗначение` и `&ПараметризованныйТест`: в этот набор их не пиши. Проверки бывают и `Ожидаем.Что`, и `Утверждения.ПроверитьРавенство`. Прогон пакета идёт через `tasks/test.os`.
