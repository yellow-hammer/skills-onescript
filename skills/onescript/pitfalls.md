# Грабли OneScript

Собрано на OneScript 2.0.1, opm 1.6.5, oneunit 0.4.1, autumn 4.3.13, winow 0.11.3.

## Язык

- У цикла `Для` нет шага. Обратный обход - `Пока` с ручным декрементом.
- Нельзя называть переменные и функции: `И`, `Или`, `Не`, `Новый`, `Символы`, `Строка`, `Число`, `Дата`, `Булево`, `Тип`, `Вычислить`. Пакет `asserts` добавляет глобальные `Ожидаем` и `Утверждения`.
- `Новый Структура("Имя,Возраст", "Иван", 30)` - первый аргумент это список ключей. `Новый Структура("a", 1, "b", 2)` создаёт один ключ `a`, остальные аргументы игнорируются.
- `Формат(0, "ЧГ=0")` возвращает пустую строку. Для нуля нужен `Формат(Значение, "ЧГ=0; ЧН=0")`.
- `ТекущаяУниверсальнаяДатаВМиллисекундах()` считает от `0001-01-01`. Unix-время: вычесть `62135596800000`.
- В `Формат` для дробных секунд есть `р` или `f`: `ДФ=ЧЧ:мм:сс.ррр`.
- Конструктор можно вызывать в выражении: `Новый Файл("a.txt").Существует()`.
- Побитовые функции работают с 32-битным знаком. Для беззнакового хеша результат приводят отдельно.
- Типа `HMAC` нет. HMAC по RFC 2104 лежит в пакете `jwt`, класс `HmacRfc2104`.
- `yaml` умеет только чтение. `ЗаписатьYAML` выбрасывает «Функционал записи yaml не реализован».
- `ПрочитатьJSON(Чтение, Истина)` возвращает `Соответствие`. Без второго аргумента получается `Структура`, и ключ, который не является идентификатором, ломает чтение.

## Исключения и лог

```bsl
ВызватьИсключение "demo: недопустимый символ";
```

Сообщение API начинается с имени пакета.

`logos`: уровень - перечисление `УровниЛога`. В шаблон `Неопределено` не подставляется (`%1` остаётся в строке). Оборачивай значение в `Строка(...)`. В `autumn-properties.json` не задавай `rootLogger`: при уровне `WARN` OneUnit печатает «Тестирование завершилось удачно» и теряет статистику. Настраивай именованный логгер пакета.

## Сеть

`ТаймаутЧтения` и `ОжидатьСоединения` задаются в миллисекундах. `ОжидатьСоединения` ждёт весь таймаут, даже если клиент уже подключился: принимай соединения коротким интервалом в цикле. `ПрочитатьСтроку` возвращает весь буфер, не одну строку. Кодировка в `ПрочитатьСтроку` и `ОтправитьСтроку` - строка `"utf-8"`, не `КодировкаТекста.UTF8`. TLS поверх `TCPСоединение` нет.

## Пакеты hub

- `semver`: `Версии.ВерсияВДиапазоне` берёт из строки только первое условие. Составной диапазон собирай через `Версии.Сравнение(">=1.0.0").ДобавитьДиапазон("<2.0.0")`. `Новый Версия("не-версия")` не исключение, а `0.0.0` с ошибкой в `Ошибка()`. `Версии.ВерсияВДиапазоне` на такой строке уже выбрасывает исключение: версию проверяй до диапазона.
- `entity` нумеруется четырьмя сегментами (`3.4.3.1`). На opm 1.4.x такой `ЗависитОт` не разбирается. Перед установкой нужен `opm update opm@1.6.5`: opm 1.5.0 чинит разбор, но подбирает `reflector` 0.6.1, который на OneScript 2.1 падает с «Тип не зарегистрирован (Object)».
- `crypto` содержит класс `JWT`. Рядом с пакетом `jwt` его не подключай.

## Пути Windows

`oneunit` ставит текущий каталог в каталог теста. Текущий каталог Windows ограничен 260 символами, длинный путь даёт `PathTooLongException`. SQLite на том же пределе пишет `unable to open database file`. Обход: `subst` на короткий диск, прогон, затем `subst X: /d`.

Порт приложения может держать контейнер. Проверка: `Get-NetTCPConnection -LocalPort <порт>`.

## Autumn и Winow

См. навыки `autumn`, `autumn-cli`, `winow`. Кратко:

- `&Желудь`, `&Дуб`, `&Контроллер` стоят сразу перед `Процедура ПриСозданииОбъекта`, после `Перем`. Аннотация в начале файла, а между ней и конструктором `Перем`, компонент не регистрирует.
- `Поделка.ПросканироватьКаталог` устарел и ничего не делает. Типы должны быть загружены до `Новый Поделка()`.
- Поле `&Пластилин` в конструкторе ещё пустое. Зависимость, нужная при создании, передавай параметром конструктора.
- Метод команды autumn-cli нельзя называть `Выполнить`.
- Контроллеры winow лежат в каталоге `winow.КаталогСПриложениями`. По умолчанию `./app`. Значение из `autumn-properties.json` применяется, если ключ задан.
- Куки: `Ответ.Куки`. Сессия пишется туда же. `Ответ.Заголовки["Set-Cookie"]` коллекцию кук не заменяет.
- SSE и WebSocket: `"ИспользоватьПрикладнойСервер": true`. Нативный `ВебСервер` их не держит.
